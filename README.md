# ✅ To-Do List Web Application

A simple and interactive To-Do List application that helps users organize and manage daily tasks efficiently. Users can add, mark, and remove tasks, making it easier to stay productive and track progress.

## 🚀 Project Overview

This project is designed to improve task management through a clean and user-friendly interface. It allows users to create task lists, mark completed tasks, and delete tasks when no longer needed.

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Interactive and responsive UI
- Real-time task updates
- Visual indicators for completed and pending tasks

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
